# Структура vault

Папка `~/ai_agent_project/vault/Агенты/`:

| Файл | Назначение |
|---|---|
| `Правила.md` | жёсткие правила: деньги, правда, журнал |
| `Полезное.md` | эндпоинты, команды, грабли |
| `Журнал - <проект>.md` | хронология проекта |
| `Предложения/*.json` | заявки агентов на скиллы и cron |
| `Операции.md` | журнал операций `hermes-ops` |
| `Деньги.json` | реестр подтверждённых выплат |

Формат записи в журнал:

```markdown
## 2026-10-20 17:05 — что сделано

Результат одной строкой.
Чем подтверждено: команда и её вывод.
Что дальше: следующий шаг.
```

Формат предложения (пишет агент, одобряет лидер, утверждает оператор):

```json
{
  "kind": "skill",
  "name": "имя-скилла",
  "why": "что делает и чем поможет",
  "why_now": "измеренный факт, почему это нужно сейчас",
  "skill_text": "---\nname: ...\ndescription: ...\n---\n\nтело"
}
```
