# Hermes Swarm Kit

Набор инструментов для самостоятельной работы команды ИИ-агентов в Hermes: роли,
общий канал, терминальный интерфейс управления, гейт на создание скиллов и cron-задач,
инструмент изменения самого Hermes и Telegram mini-app.

Собрано 20 октября 2026 года на одной машине Ubuntu 24.04.

---

## Что внутри

| Папка | Что это |
|---|---|
| `plugins/hermes-ops/` | плагин: агентам даётся инструмент менять сам Hermes — плагины, скиллы, cron, конфиг, git |
| `plugins/agent-board/` | плагин: вкладка «Агенты» в дашборде Hermes — карта пузырей, доска, переписка |
| `scripts/agent_tui.py` | терминальный интерфейс (curses, мышь) — основной рабочий инструмент оператора |
| `scripts/agent_tui_start.sh` | запуск TUI в tmux-сессии `hermes-agents` |
| `scripts/make_role.py` | библиотека ролей: `leads`, `copy`, `designer`, `watcher`, `sourcer` |
| `scripts/agent_board.py` | отдельный веб-сервер карты (порт 9121), если TUI не подходит |
| `docs/` | гайды: установка, роли, протокол согласования, архитектура |
| `roles/` | шаблоны ролей и SOUL.md |
| `vault/` | структура папки vault, журналы, предложения, реестр денег |

---

## Установка за пять минут

```bash
# 1. Плагин изменения Hermes
cp -r plugins/hermes-ops ~/.hermes/plugins/
hermes plugins enable hermes-ops
hermes tools enable hermes_ops --platform cli

# 2. Вкладка «Агенты» в дашборде
cp -r plugins/agent-board ~/.hermes/plugins/
hermes plugins enable agent-board
hermes dashboard --port 9119 --no-open     # вкладка: /agents

# 3. Терминальный интерфейс
mkdir -p ~/.hermes/scripts
cp scripts/agent_tui.py scripts/agent_tui_start.sh scripts/make_role.py ~/.hermes/scripts/
bash ~/.hermes/scripts/agent_tui_start.sh demo-sites
tmux attach -t hermes-agents
```

## Как это работает

### Команда

Команда Agora — набор **настоящих профилей Hermes**, у каждого свой SOUL.md, своя память
и свой набор скиллов. Роли: `leader` (ведёт обсуждения и нанимает), `developer`,
`reviewer`, `tester`, `devops`, `researcher`, `writer`, `sourcer` (ищет, где платят).

```bash
hermes agora list              # обсуждения
hermes agora show <id>         # полный транскрипт обсуждения
hermes agora result <id>       # принятое решение
hermes kanban list             # все задачи обеих досок
hermes kanban tail <task_id>   # живая лента событий
```

### Канал — единое место разговора

Командный канал проекта — постоянная задача в статусе `scheduled`.
Агенты пишут туда через `agora_message`, лидер читает через `agora_read_chat`.
Оператор тоже пишет в этот канал — из TUI (клавиша `s`) или из mini-app.

**Важно:** лидер читает только структурные сообщения с префиксом `[agora:msg]`.
Сырой комментарий в базе он не увидит. Поэтому сообщение оператора пишется
именно в этом формате — иначе вопрос останется без ответа.

### Найм

Лидер сам нанимает сотрудника, когда команде не хватает роли:

```python
agora_hire_worker(name="sourcer2", role="sourcer",
                  team="crypto-squad", project="crypto-earn",
                  why="ищет каналы, где платят, отдельно от разработки")
```

Воркер — полноценный профиль, сразу начинает получать задачи от диспетчера.
Подробности: `docs/roles.md`.

### Гейт: скиллы и cron — только по согласованию

Агент **не может** сам создать скилл, cron-задачу или скрипт. Путь:

1. Агент пишет JSON-предложение в `vault/Агенты/Предложения/`.
2. Лидер на heartbeat проверяет папку и ставит `endorsed: true` **с причиной**.
3. Оператор в TUI (экран «ПРЕДЛОЖЕНИЯ») жмёт `a` — и только тогда скилл создан
   или cron запущен.

Без `endorsed` инструмент отказывает: «лидер не согласовал». Проверено вживую.

### Деньги

`vault/Агенты/Деньги.json`:

```json
{"total_usd": 0.0, "items": [{"date": "2026-10-20", "channel": "POIDH 1495",
  "amount": "0.0108 ETH", "status": "pending vote", "proof": "0xfb92e00a…"}]}
```

Заполняет оркестратор или лидер, **только с tx hash**. Экран «ДЕНЬГИ» в TUI читает файл.

## Терминальный интерфейс

```bash
tmux attach -t hermes-agents
```

| Экран | Клавиша | Что там |
|---|---|---|
| ДОСКА | `1` | задачи слева, статусы агентов справа |
| АГЕНТЫ | `2` | задачи каждого агента, текущие и выполненные |
| ПЕРЕПИСКА | `3` | канал проекта |
| ПРЕДЛОЖЕНИЯ | `4` | заявки на скиллы и cron, утверждение и отклонение |
| ДЕНЬГИ | `5` | подтверждённые выплаты |

| Клавиша | Действие |
|---|---|
| `a` | назначить задачу агенту (на экране предложений — утвердить) |
| `b` | заблокировать задачу с причиной |
| `u` | разблокировать |
| `c` | закрыть задачу |
| `s` | написать указание лидеру в канал |
| `w` | разбудить лидера немедленно |
| `r` | отклонить предложение (на экране предложений) |
| `q` | выход |

Мышь: клик по задаче выбирает её, клик по колонке агентов открывает его карточку.

## Библиотека ролей

```bash
python3 ~/.hermes/scripts/make_role.py list
python3 ~/.hermes/scripts/make_role.py install leads --team site-factory --project demo-sites
```

| Роль | Роль в Agora | Для чего |
|---|---|---|
| `leads` | researcher | охота за малыми компаниями без своего сайта; справочники сайтом не считаются |
| `copy` | writer | письма по-человечески, ни одного выдуманного числа |
| `designer` | developer | одностраничники, которые правятся глазами до показа |
| `watcher` | devops | сторож: пишет в свой файл, молчит без изменений |
| `sourcer` | sourcer | ищет, где реально платят, и доказывает рельс живым запросом |

Установка создаёт профиль, пишет SOUL.md, подключает скиллы, добавляет в команду
и убирает Telegram-токен из `.env` профиля (один бот — один профиль).

## Инструмент изменения Hermes

Плагин `hermes-ops` даёт агентам инструменты:

| Инструмент | Что делает |
|---|---|
| `hermes_ops_status` | профили, плагины, скиллы, cron, диск |
| `hermes_ops_plugin_install` | поставить плагин из каталога или GitHub |
| `hermes_ops_plugin_toggle` | включить/выключить плагин |
| `hermes_ops_plugin_remove` | удалить плагин — только `allow_destructive=true` |
| `hermes_ops_skill_install` | поставить скилл из реестра |
| `hermes_ops_cron_create` | создать cron — только с `endorsed=true` |
| `hermes_ops_cron_pause` | остановить/возобновить cron |
| `hermes_ops_config_get` | прочитать значение из config.yaml |
| `hermes_ops_git_publish` | закоммитить и запушить папку |

Правила, которые инструмент держит сам: никаких денежных команд (список запрещённых
подстрок), никакого удаления без явного флага, каждый вызов пишется в
`vault/Агенты/Операции.md`.

## Подталкивание

```bash
python3 ~/.hermes/scripts/nudge.py
```

Cron `agora-nudge` каждые 10 минут: если команда молчит дольше 25 минут или стоит
с задачами в очереди — шлёт в канал короткое указание с одним ожидаемым действием
и будит лидера. Подробности: `docs/NUDGE.md`.

## Ограничения, которые нельзя забывать

- **Один кошелёк**: `0xC9D0aB76b5e9CBE3Da320347cCDAa111e515e6D0`, сеть Base.
- **Газ**: не больше 0.0002 ETH за транзакцию, 0.0005 ETH в сутки.
- **Без разрешения оператора**: покупки, подписки, пополнения, залоги, переводы, новые кошельки.
- **Ключи и seed-фразы** не читать, не печатать, не копировать в файлы.
- **Ни одной цифры без источника** — число, которое не измерено в этой сессии, не пишется.
- **Права на запись** в канал и журналы — только у своей команды.
