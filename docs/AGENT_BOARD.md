# Agent Board

Два способа смотреть за агентами: вкладка в дашборде Hermes и отдельный сервер.

## Вкладка в дашборде (основная)

`http://127.0.0.1:9119/agents` — вкладка «Агенты» рядом с Kanban.

Плагин `plugins/agent-board/`:

| Файл | Роль |
|---|---|
| `plugin.yaml` | манифест плагина Hermes (имя, provides_tools) |
| `dashboard/manifest.json` | вкладка дашборда: `path: /agents`, `entry: dist/index.js`, `api: plugin_api.py` |
| `dashboard/dist/index.js` | фронтенд на Plugin SDK: React и компоненты берутся из дашборда, сборка не нужна |
| `dashboard/plugin_api.py` | API под префиксом `/api/plugins/agent-board/` |

**API:**

| Метод | Путь | Что возвращает |
|---|---|---|
| GET | `/projects` | список проектов со счётчиками и последним сообщением |
| GET | `/project/{name}` | агенты (с задачами), лента переписки, id канала |
| POST | `/say` | сообщение оператора в канал + разбудить лидера |

Ответ `/project/{name}`:

```json
{"name": "crypto-earn",
 "agents": [{"name": "scout", "status": "running",
             "counts": {"running": 1, "ready": 0, "blocked": 0, "todo": 0, "done": 9},
             "current": [{"id": "t_...", "title": "...", "status": "running"}],
             "done": [...]}],
 "feed": [{"author": "оператор", "body": "...", "ts": 1792501613, "task_id": "t_..."}],
 "channel": "t_d4f22e06"}
```

### Пузырь — это агент, не задача

- Имя и число задач в работе внутри пузыря.
- **Цвет = статус:** зелёный работает, синий ждёт запуска, красный заблокирован, серый свободен.
- **Анимация = статус:** зелёные точки летят по орбите (работает), синяя пунктирная рамка
  бежит по кругу (ждёт), красное кольцо пульсирует (блок). Число летящих точек равно
  числу задач в работе.
- **Лидер в центре**, от него лучи ко всем остальным — видно, кто кем управляет.
- **Наведение** — всплывашка с задачами в работе, полными названиями, до четырёх и «ещё N».
- **Клик** — панель агента: сначала текущие задачи по приоритету, ниже выполненные.

Справа: поле «Написать команду…», кнопка «Отправить и разбудить лидера», вкладки
**Агент / Переписка / Все задачи**. Сверху — таблетки проектов с точками статуса.

### Воркеры без задач видны

Канбан показывает только задачи. Нанятый сотрудник без задач в списке **исчез** — это
выглядит как «найм не сработал». Поэтому API дополнительно читает реестр команд Agora
через `get_team_for_project` и добавляет таких воркеров со статусом «свободен».

## Отдельный сервер (запасной вариант)

```bash
python3 ~/.hermes/scripts/agent_board.py --port 9121
```

Самодостаточная страница без дашборда: список проектов → отдельная страница на проект.
API: `/api/projects`, `/api/project/{name}`, `POST /api/say`. CORS включён, так что к нему
можно обращаться извне (например, из Telegram mini-app).

Сервис:

```ini
# ~/.config/systemd/user/agent-map.service
[Service]
Type=simple
ExecStart=/usr/bin/python3 /home/asd/.hermes/scripts/agent_board.py --port 9121
Environment=HOME=/home/asd
Restart=on-failure
RestartSec=5
```

## Ошибки, которые уже были

| Симптом | Причина | Лечение |
|---|---|---|
| «командный канал проекта не найден» | проект в статусе `completed`, Agora удалила его задачи вместе с каналом | `update_project(project_name=..., reactivate=True)` |
| агент есть в команде, но не на карте | карта читала только канбан | читать реестр команд Agora |
| сообщение оператора не видно лидеру | записано сырым комментарием, а `agora_read_chat` парсит только `[agora:msg] ` | писать в формате `[agora:msg] {json}` |
| вкладка не появилась в дашборде | нет `plugin.yaml` или плагин не включён | `hermes plugins enable agent-board` + рестарт дашборда |
| API отвечает 401 | дашборд требует авторизацию | это норма для `/api/plugins/*`, данные читаются из той же сессии браузера |
