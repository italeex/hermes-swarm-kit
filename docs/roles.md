# Роли и найм

## Построенные роли Agora

| Роль | Шаблон | Что делает |
|---|---|---|
| `leader` | Team Leader | ведёт обсуждения, арбитраж, нанимает, отвечает оператору в канале |
| `developer` | Developer | реализация, тесты, зависимости |
| `reviewer` | Reviewer | проверка корректности, безопасности, соответствия задаче |
| `tester` | Tester | тест-стратегии, баг-репорты с шагами воспроизведения |
| `devops` | DevOps | cron, деплой, инфраструктура, сторожи |
| `researcher` | Researcher | веб-ресёрч, проверка фактов, ссылки на источники |
| `writer` | Writer | тексты, письма, отчёты |
| `sourcer` | Sourcer | **ищет, где платят**, проверяет платёжный рельс, закрывает мёртвые каналы |

Роль `sourcer` добавлена в `agora/agora/worker_templates.py` — с полным SOUL.md
и правилами: не выдумывать числа, проверять рельс до начала работы, писать
доказательство в журнал.

## Найм

### Кто нанимает

Лидер, сам, без согласования — если команде не хватает роли. Правило в
`_HEARTBEAT_PROMPT` (agora/agora/leader_loop.py):

> HIRING: если задача требует роли, которой в команде нет, нанимай сам через
> `agora_hire_worker` и объяви в канале, кого нанял и что он будет делать.
> Не нанимай на роль, которую команда уже закрывает.

### Как

```python
agora_hire_worker(
    name="sourcer2",          # имя профиля: строчные буквы, цифры, дефис
    role="sourcer",           # шаблон роли
    team="crypto-squad",      # команда, в которую попадёт
    project="crypto-earn",    # проект
    why="ищет каналы, где платят, отдельно от разработки",
)
```

Что происходит внутри: создаётся профиль Hermes с клонированным `config.yaml`
и `.env`, генерируется SOUL.md, воркер добавляется в состав команды и сразу
начинает получать задачи от диспетчера.

### Вручную (когда лидер не справился)

```python
import sys; sys.path.insert(0, "/home/asd/.hermes/plugins")
from agora.agora.worker_manager import create_worker
from agora.agora.team_manager import add_worker_to_team, _bind_team_to_project, _add_project_to_worker

create_worker(name="sourcer", role="sourcer")
add_worker_to_team("crypto-squad", "sourcer")
_bind_team_to_project("crypto-squad", "crypto-earn")   # без этого диспетчер не знает проект
_add_project_to_worker("sourcer", "crypto-earn")
```

**Ловушка:** `create_team(team_name, worker_names)` без `project` оставляет
`team["project"] = None` и не вызывает `_add_project_to_worker`. Задачи проекта
тогда не маршрутизируются ни к кому. Всегда привязывайте вручную.

**Ловушка:** после `create_worker` уберите из `.env` профиля строки
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_USERS`, `TELEGRAM_HOME_CHAT`.
Профиль клонируется с `.env` корня, иначе четыре профиля спорят за одного бота,
а gateway отказывается мигрировать.

## Библиотека ролей

`scripts/make_role.py` — установка готовых ролей под задачу.

```bash
python3 ~/.hermes/scripts/make_role.py list
python3 ~/.hermes/scripts/make_role.py show leads
python3 ~/.hermes/scripts/make_role.py install leads --team site-factory --project demo-sites
```

| Роль | Команда | Суть |
|---|---|---|
| `leads` | site-factory | охота за малыми компаниями без своего сайта |
| `copy` | site-factory | письма по-человечески, ни одного выдуманного числа |
| `designer` | site-factory | одностраничники, правятся глазами до показа |
| `watcher` | crypto-squad | сторож: пишет в свой файл, молчит без изменений |
| `sourcer` | crypto-squad | ищет, где платят, и доказывает рельс живым запросом |

Каждая роль = профиль + SOUL.md + стартовые скиллы. Правила роли зашиты в SOUL:

**leads**
- сайтом компании не считаются карточки 2ГИС, Яндекс.Карт, Zoon, ПроДокторов, avito, VK,
  авто-страницы `company.2gis.biz` и поддомены справочников (`*.gidm.ru`, `*.gdekrasa.ru`);
- `website_tag` в базе лидов пуст во всех строках — это незаполненное поле, а не признак;
- каждый лид проверяется живым запросом, адрес берётся из карточки.

**copy**
- ни одного выдуманного числа, факта, отзыва или цены;
- конкретный измеренный дефект вместо «ваш сайт устарел»;
- не длиннее 7 строк, последняя строка — один понятный следующий шаг;
- опт-аут «Если не интересно, просто скажите, и я больше не напишу».

**designer**
- один файл `index.html`, без внешних зависимостей;
- цены-примеры помечены, бейдж «демо» заметен;
- перед показом — скриншот 390 px и проверка глазами, потом правка и новый скриншот.

**watcher**
- пишет в свой файл, а не в общий лог, молчит без изменений;
- сам себя останавливает, когда цель достигнута или канал мёртв;
- новый cron — только через предложение.

**sourcer**
- платёжный рельс проверяется живым запросом ДО начала работы;
- мёртвый канал закрывается с доказательством, почему он мёртв;
- ни одной цифры, которая не измерена в этой сессии.

## Как добавить свою роль

1. Описать роль в `make_role.py` → `ROLES`: заголовок, роль Agora, цель, правила, скиллы.
2. `python3 make_role.py show <имя>` — проверить SOUL.
3. `python3 make_role.py install <имя> --team <команда> --project <проект>`.

Свою роль Agora (не из библиотеки) можно добавить в
`agora/agora/worker_templates.py` — словарь `TEMPLATES`, ключ роли, `soul_template`,
`toolsets`, `model`.
